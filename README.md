# Статблоки для мастера (Owlbear Rodeo)

Личная библиотека статблоков. Видна и доступна только мастеру.

## Почему игроки не увидят статблоки

Текст статблоков хранится только в браузере мастера (localStorage на домене расширения).
Он не отправляется в Owlbear Rodeo: ни в комнату, ни в сцену, ни в токены, поэтому на устройства игроков
эти данные не попадают. В токен записывается только случайный идентификатор связи.
Игрок, открывший окно расширения, видит лишь надпись «Только для мастера».

Обратная сторона: статблоки лежат на одном устройстве. При очистке данных браузера или смене компьютера
они пропадут, поэтому периодически делайте резервную копию (Импорт / экспорт → Скачать .json).

## Как пользоваться

- **＋ Новый** — создать статблок (есть кнопка «Вставить шаблон 5e»). Текст в Markdown.
- **Импорт / экспорт** — загрузить файлы .md / .txt / .json. Большой файл можно разделить на статблоки
  по заголовкам «# » или «## ». Повторный импорт файла с тем же названием обновляет статблок, а не дублирует.
- **Привязка к токену** — выберите токен на карте, откройте статблок, нажмите «Привязать к выбранному токену».
- **Правый клик по токену → «Статблок»** — откроет привязанный статблок. Если статблока ещё нет,
  откроется список, и выбранный статблок привяжется к этому токену.

## Размещение на GitHub Pages

Положите папку целиком в тот же репозиторий, где лежит «Очередь заявок», под именем `statblocks`
(получится `репозиторий/statblocks/manifest.json`). В `manifest.json` замените `ВАШ_НИК` и `ИМЯ_РЕПОЗИТОРИЯ`
(4 строки). Ссылка на манифест:
`https://ВАШ_НИК.github.io/ИМЯ_РЕПОЗИТОРИЯ/statblocks/manifest.json`
